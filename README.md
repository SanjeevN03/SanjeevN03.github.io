# Unicorn Solar Energy — Version 0.1

Astro homepage for **Unicorn Solar Energy — Complete Solar & Energy Solutions**.

## Included
- Responsive homepage and mobile navigation
- Solar (on-grid, off-grid, hybrid, ground-mounted), BESS, solar water heating, heat pump and net-metering services
- Industries section focused on commercial premises, schools, industry and hotels
- “How We Design a Solar System” process
- Component/brand overview
- Selected installation gallery using supplied photos; GPS-overlay versions are intentionally excluded
- Contact details, Google Maps directions, Facebook link
- Enquiry form that opens WhatsApp with a pre-filled message for the visitor to review and send
- Mobile sticky Call / WhatsApp / Quote bar
- GitHub Actions workflow for free GitHub Pages deployment

## Configure GitHub Pages
1. Create a public repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace the placeholder with your GitHub username).
2. Edit `astro.config.mjs` and replace `YOUR-GITHUB-USERNAME` with your actual GitHub username. The `base: '/'` setting is correct for this repository name.
3. Upload/push these files to the `main` branch.
4. In GitHub, open **Settings → Pages** and set the build source to **GitHub Actions**.
5. The workflow will build and deploy the site at `https://YOUR-GITHUB-USERNAME.github.io`. GitHub Pages hosting is free for this public repository.

## Run locally
Install Node.js 20+, then run `npm install`, `npm run dev`. Build with `npm run build`.
